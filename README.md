One funny fortune cookie message for an AI agent — a single line, in the
voice of a fortune slip. Entry for the
[make.fun bounty](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

## The fortune

> You will meet a tall, dark stranger. He is a prompt injection. Walk away.

## Run

```bash
node main.ts
```

`main.ts` writes the fortune to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`): exactly one line, 73 bytes, no trailing
newline. Deterministic, no network, no input.
